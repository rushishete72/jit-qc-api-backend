# 💾 JIT/QC Database Management System Overview

यह दस्तावेज़ JIT/QC एप्लिकेशन में डेटाबेस कनेक्शन, यूटिलिटी फ़ंक्शन्स, और रीसेट/सीडिंग प्रक्रिया को नियंत्रित करने वाली मुख्य Node.js स्क्रिप्ट्स का **मास्टर ब्लूप्रिंट** है।

---

## 1. database/db.js: The Core Connector

यह फ़ाइल **pg-promise** लाइब्रेरी का उपयोग करके PostgreSQL के साथ एप्लिकेशन-व्यापी (application-wide) इंटरफ़ेस स्थापित करती है। यह डेटाबेस इंटरैक्शन का एकल स्रोत (Single Source of Truth) है।

### 🛠️ मुख्य निर्यात (Key Exports):

| निर्यात (Export) | प्रकार | उपयोग |
| :--- | :--- | :--- |
| **`db`** | Object | pg-promise का मुख्य डेटाबेस ऑब्जेक्ट, जिसका उपयोग क्वेरीज़ चलाने के लिए किया जाता है। |
| **`pgp`** | Object | pg-promise का लाइब्रेरी इंस्टेंस, जिसका उपयोग फ़ॉर्मेटिंग और यूटिलिटीज़ के लिए किया जाता है। |
| **`initializeDB()`** | Function | क्रेडेंशियल्स की जाँच और होस्ट की पहुँच सुनिश्चित करने के लिए **प्री-फ़्लाइट कनेक्शन चेक** करता है। |
| **`dropAllTables()`** | Function | `public` स्कीमा में मौजूद **सभी यूज़र-डिफाइंड टेबलों** को सुरक्षित रूप से हटाता है (`CASCADE` के साथ)। |

### 🔒 डिप्लॉयमेंट/SSL कॉन्फ़िगरेशन:

* कनेक्शन सेटिंग्स **Environment Variables** से आती हैं (जैसे `DB_HOST`, `DB_NAME`, `DB_USER`)।
* **क्लाउड-रेडी:** यह **`DB_SSL=true`** एनवायरनमेंट वेरिएबल को चेक करता है। यदि यह **`true`** है, तो यह क्लाउड डिप्लॉयमेंट प्लेटफ़ॉर्म (जैसे Render) के लिए आवश्यक SSL कॉन्फ़िगरेशन (`{ rejectUnauthorized: false }`) को स्वचालित रूप से लागू करता है।

## 2. database/reset_and_seed.js: The Database Lifecycle Script

यह स्क्रिप्ट **डेवलपमेंट, स्टेजिंग, या CI/CD टेस्टिंग** के लिए डेटाबेस को एक स्वच्छ, ज्ञात (known), और कार्यात्मक (functional) स्थिति में रीसेट करने के लिए ज़िम्मेदार है।

### ⚙️ चलाने का कमांड:
```bash
node database/reset_and_seed.js
